Por qué tiene sentido para una agencia de automatización

  • Cero infraestructura: sin VPS, sin instancia de WhatsApp que mantener y sin base de datos que cuidar.
  • WhatsApp oficial: Cloud API de Meta con coexistencia, más estable que la conexión por código QR.
  • Atención que se convierte en venta: cada conversación cae en un embudo, con cola de atención y paso a un humano.
  • Se integra con lo que ya usas: API y webhooks para n8n, Make y Zapier.

Prompt listo en minutos

Qué incluye el paquete de IA

La infraestructura que tu agencia no necesita construir.

Agente de IA

Instrucción estructurada o libre, base de conocimiento con archivos, transcripción de audios y escalamiento humano en horario comercial.

WhatsApp oficial

Cloud API de Meta, incluso en coexistencia con el WhatsApp Business del cliente, con historial importado.

CRM + cola de atención

Cada contacto nuevo se convierte en una tarjeta del embudo. La cola reparte las conversaciones entre los agentes cuando la IA pasa a un humano.

API y webhooks

Claves de API para contactos, oportunidades y proyectos, y webhooks de eventos del embudo para disparar tus flujos.

Preguntas frecuentes

¿El agente de IA tiene límite de atenciones?

El precio del Agente de IA cubre hasta 500 atenciones al mes por cliente. Por encima de eso, nuestro equipo comercial se pone en contacto para ajustar el valor.

¿Puedo integrarlo con n8n o con mi propia automatización?

Sí. Con las claves de API creas y consultas contactos, oportunidades y proyectos, y los webhooks avisan en tiempo real cuando una tarjeta cambia de etapa o se gana un lead. Ver la documentación de la API.

¿La IA agenda citas?

Hoy el agente envía el link de agendamiento para que el lead elija el horario. La integración directa con calendarios está en el roadmap.

¿Quién paga los mensajes del WhatsApp oficial?

En la API oficial, Meta cobra por los mensajes de plantilla, que son los que se usan para iniciar conversaciones. El cobro lo hace Meta, en la cuenta de WhatsApp Business del número conectado.
